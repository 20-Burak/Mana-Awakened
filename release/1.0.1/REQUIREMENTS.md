# Requirements

| | |
|---|---|
| Minecraft | **1.21.1** |
| Mod loader | **NeoForge 21.1.0 or later** (any 1.21.1 build) |
| Java | **21** |
| Required mod | **[Player Animator](https://modrinth.com/mod/playeranimator)** (KosmX), any **2.x** build for Minecraft 1.21.1 (2.0.0 or later; 2.0.0 and 2.0.4 were tested). Needed on the **client and the server**. Iron's Spells needs it too, so a pack with Iron's already has it: keep only one copy. |

## Optional

None of these is needed; when present, they share Mana Awakened's mana pool (each can be switched off on its own in the server config: `unifyIrons`, `unifyArs`, `unifyMahou`).

| Mod | Accepted | Tested |
|---|---|---|
| Iron's Spells 'n Spellbooks | 1.21-3.4.4 or later | 1.21-3.4.4 and 1.21.1-3.16.3 |
| Ars Nouveau | 5.8.2 or later | 5.8.2 and 5.13.3 |
| Mahou Tsukai | 1.21.0-v1.35.12 or later | 1.21.0-v1.35.12, 1.21.1-v1.36.27 and 1.21.1-v1.36.28 |
| Curios API | 9.0.5 or later (as Iron's Spells requires) | 9.2.0 and 9.5.1 |

Newer builds than the tested ones are accepted and tried; an older one is refused at start by NeoForge with a message naming the version needed.

Iron's Spells and Ars Nouveau bring their own requirements (Iron's Lib, GeckoLib, Curios); install those as their pages say.

## Server

Install Mana Awakened and Player Animator on the server and on every client.
